# Sonidos de la batería

Dominio público (CC0 1.0): https://creativecommons.org/publicdomain/zero/1.0/

Salen de **Virtuosity Drums**, de Versilian Studios (CC0):
https://github.com/sfzinstruments/virtuosity_drums

Cada sonido mezcla los micrófonos cercanos (bombo y caja), los aéreos y algo
de sala del kit original, en mono a 48 kHz y 16 bits, recortado y con un
fundido al final. Las claves (`sticks.wav`, la cuenta de entrada) son del
mismo kit (percusión, Claves1).

| Archivo | Original |
|---|---|
| kick.wav | kick_snoff_vl3_rr1 |
| snare.wav | snare_center_vl28 |
| snare_soft.wav | snare_center_vl14 |
| xstick.wav | snare_crossstick_vl12 |
| hat.wav | hh_closed_vl3_rr1 |
| hat_soft.wav | hh_closed_vl2_rr1 |
| hat_open.wav | hh_open_vl3_rr1 |
| ride.wav | ride_ride_vl2_rr1 |
| crash.wav | crash_crash_vl2_rr1 |
| sticks.wav | Claves1_Hit_v2_rr1 |

Se generan con `app/tool/make_drums.py` a partir de una copia del kit.
